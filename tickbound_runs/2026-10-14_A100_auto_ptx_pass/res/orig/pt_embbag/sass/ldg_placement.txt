Where the global loads sit in the steady-state bag loop (nvcc 12.6.85 timing build, `cuobjdump -sass`).
Order of memory instructions in one loop trip (4 bag elements): I = index load (LDG.E.64 input[emb]),
G = weight gather (LDG.E weightFeat[idx * stride0]), P = per_sample_weights load, S = offset2bag store
(@!P STG.E.64). 'gap' = instructions from each gather to the first instruction that uses its value.
cyc/trip = one-warp simulation (tools/sassmodel.py) with index loads 39 cycles (L1), per_sample_weights
39, gathers at L2 near/far and DRAM near/far latencies. 'exposed' = gather latencies one trip waits
through = slope dT1/dL of cyc/trip between the lowest and highest latency (4 = the 4 gathers serialized,
1 = all 4 in flight together); the memory order alone does not show it, the scoreboard waits do.
